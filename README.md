# ARES SOS

A NASA-inspired sci-fi rescue game built with React and an HTML5 Canvas. Pilot through an asteroid field, then defend the Mars outpost from an alien assault.

## Run locally

```sh
npm install
npm run dev
```

Use the development server's local URL to play. Build a production bundle with `npm run build`.

## Controls

- **Asteroid flight:** WASD or arrow keys to maneuver; hold Space to fire twin lasers.
- **Mars surface:** A/D to move, W or Space to jump, and J or mouse click to fire.

The opening transmission uses the supplied `public/clip1.mp4` and `public/clip2.mp4` videos. Use **Skip** to begin flying immediately. The game synthesizes its sound effects in the browser.
